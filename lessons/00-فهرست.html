دوره جامع Laravel

Laravel از پایه

سفر یادگیری را از این‌جا شروع کن؛ با مهارتِ PHP که داری، قدم‌به‌قدم یک فروشگاه کوچک واقعی می‌سازی.

چطور از این دوره استفاده کنم؟

از درس ۱ شروع کن
درس‌ها به ترتیب شماره کنار هم قرار گرفته‌اند؛ اولی را باز کن و جلو برو.
🚀
پروژه‌محور
هر درس یک «گام پروژه» دارد؛ در پایان، یک فروشگاه کوچک کامل ساخته‌ای.
★
خلاصه‌ی طلایی
آخر هر درس، نکته‌هایی که باید توی ذهنت بماند، جمع شده است.
🎯 پیش‌نیازها
  • PHP 8.3+ — باید بلد باشی (متغیر، آرایه، تابع، class، PDO).
  • Composer — برای ساخت پروژه و نصب پکیج‌ها.
  • SQLite یا MySQL — دیتابیس (پیش‌فرضِ نسخه‌های جدید SQLite است).
  • ادیتور کد — VS Code یا PHPStorm.
